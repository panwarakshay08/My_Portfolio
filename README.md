# Akshay Kumar Cinematic Portfolio

A customized cinematic Next.js portfolio for Akshay Kumar, focused on full-stack engineering, performance-focused frontends, and scalable backend services.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Main content files

- `data/profile.json` - profile, experience, featured work, links, and skills
- `data/content.json` - section labels, hero pills, and footer copy
- `public/assets/hero1.png` - hero portrait
- `public/assets/akshay-about.png` - about portrait
- `public/assets/akshay-footer.jpeg` - footer portrait
